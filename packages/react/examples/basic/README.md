# ChaSet Studio (React Showcase & Theme Workbench)

An interactive theme customizer, component gallery, and code exporter for `@chahu/cha-set`.

## Features

- **Live Theme & Style Tuner**: Real-time manipulation of light/dark mode, accent presets, corner radii, and fine-grained color overrides (`--primary`, `--secondary`, `--destructive`, `--background`, `--card`, `--ring`).
- **Interactive Component Sandbox**: Live prop toggling for Button (`variant`, `size`, `loading`, `disabled`, `fullWidth`, Base UI polymorphic `render` prop) with synchronized JSX code generation.
- **Full Component Matrix**: Inspect all variations across normal, hover, loading, and disabled states.
- **One-Click Export**: Copy ready-to-use CSS Variables, Tailwind v4 `@theme`, React JSX, Qt QML, or JSON token configs directly.

## Running Locally

From the root directory:

```bash
pnpm showcase
# or
pnpm dev
```

Or from this directory:

```bash
pnpm dev
```
