# 2026-09-13 跨平台排版（Typography）统一系统

## 目标
消除 React(Web) 与 Qt(Desktop) 的字体渲染差异：统一**字体族 / 字号 / 字重 / 行高**，
重点修 Code Block 行高不一致，并覆盖全部组件。基线 `3a619e3`（当时 gate 全绿）。

## 核心结论：漂移的真正来源
现有像素基准（Tabs 0.03%、Card 0.02%）之所以能过，是**巧合**——Qt 默认
`fontMetrics.lineSpacing`(Consolas@12=14px) 恰好接近 Tailwind `text-xs`(12px/16px)。
真正的破裂点是 React 里**显式覆盖**的 `leading-[1.4]` 等值：Qt 端**根本没有对应机制**，
`ChaSetHighlightedCode.qml` 虽然声明了 `property real lineHeight: 1.4`，但**从未作用到 TextEdit**。
→ React 16.8px/行 vs Qt 14px/行，差 2.8px/行。

## Qt 字体语义（运行时探针实测，`qml.exe` + `QT_QPA_PLATFORM=offscreen`）
1. **`font.family: "Consolas, monospace"`（逗号列表）不解析** → `fontInfo.family` 返回 `""`，
   回落到默认 "Sans Serif"。**Qt 只认单一族名**（或 Qt6.9+ 的 `font.families` 数组）。
   仓库里 47 处逗号栈字面量实际全部失效 → 必须用单族名。
2. `Text.lineHeight` + `lineHeightMode: Text.FixedHeight` → 精确 px 行高。
3. RichText `TextEdit` 的 `<p style="line-height:17px">` → 精确 17px/行；
   `<p style="line-height:140%">` → 19.59px/行（**% 不可靠，必须用 px**）；
   无 style 的 `<p margin:0>` → 14px/行。
4. Qt 布局单位是 1/64 px → `lineHeightPx()` 用 `Math.round(v*64)/64` 吸附（如 12×1.4=16.796875）。

## 落地设计（全部走 Single Source of Truth）
- **`spec/tokens/primitives.json` 新增 `primitives.typography`**：`fontFamily{sans,mono}`（存 web 栈 +
  Qt 单族名）、`fontSize{nano9,micro10,caption11,small12,body14,heading16,subheading18,title28}`（px 整数）、
  `lineHeight{none/tight/snug/normal/relaxed/code… + 每个字号一个 ratio}`、`letterSpacing{tighter…widest}`。
  `primitives.fontWeight` 扩到 regular400/medium500/semibold600/bold700。
- **`spec/token-helpers.mjs`**：新增 `FONT_FAMILY_ORDER / FONT_SIZE_ORDER / LINE_HEIGHT_ORDER /
  LETTER_SPACING_ORDER` + `camel`/`pascal` 辅助，保证 `stringifySorted` 确定性输出。
- **`spec/generators/generate-css.mjs`** → `tokens.css` 出 `--cs-font-{sans,mono}`、
  `--cs-text-*`(**px→rem，`px*0.0625`**，遵守仓库 "CSS 禁裸 px" 红线)、`--cs-leading-*`(纯比例)、
  `--cs-tracking-*`(em)、`--cs-font-weight-*`。:root 与 .dark 双写（排版与主题无关）。
- **`spec/generators/generate-qt.mjs`** → 新单例 **`qt/src/Typography.generated.qml`**：
  `familySans/familyMono`(单族名)、`size*`、`leading*`、`tracking*`、`weight*`，
  以及 **`lineHeightPx(sizePx, name)` / `trackingPx()`** 访问器（Qt 端唯一的行高换算入口）。
  CMakeLists 加 `set_source_files_properties(... QT_QML_SINGLETON_TYPE TRUE)` + QML_FILES。
- **`spec/qt-mapping.json`**：4 个 `fontSize*` 契约键改指向 `primitives.typography.fontSize.*`
  （**Qt 契约字段名/数量不变**，`theme_tokens.generated.h` 只变值）。
- **`packages/react/src/styles/theme.css`**：把令牌栓到 Tailwind v4 命名空间 —— `--font-sans/--font-mono`、
  `--text-xs/sm/base/lg` 别名 + `--text-<role>--line-height` 伴随值、`--leading-*`、`--tracking-*`；
  另加 `@utility cs-code{font-family:var(--cs-font-mono);font-size:var(--cs-text-small);
  font-weight:var(--cs-font-weight-regular);line-height:var(--cs-leading-code)}`、
  `@utility cs-code-label{…caption…}`。
- **`scripts/check-typography-parity.mjs`** + `scripts/typography-allowlist.json`：
  断言 (1) 每个 typography 值同时出现在 `tokens.css` 与 `Typography.generated.qml`；
  (2) `qt/src/` 无逗号字体族字面量、无裸 `font.pixelSize:<数字>`；
  (3) React 无裸 `text-[…px/rem]`/`font-family`/`leading-[…]`。已挂进 `pnpm gate`。
- 文档：`docs/architecture/typography-system.md`（新建）+ `docs/token-mapping.md` 更新。

## 关键取舍
- **`fontSize.body` 13 → 14**：React 侧根本没有 13px（grep 证实），13 是 Qt 独有的"幽灵档位"。
  合并 `body/bodyLarge` 为 `body:14`（= Tailwind `text-sm`），并把所有 Qt `sizeBody` 消费点对齐。
- **Qt 端 line-height 落点**：`ChaSetHighlightedCode.qml` 改为
  `lineHeightPx: Typography.lineHeightPx(root.fontSize, root.lineHeight)`，富文本包
  `"<p style=\"margin:0;line-height:" + lineHeightPx + "px\">"` —— **用 px 不用 %**。
- **组件内条件/派生字号也令牌化**（`ChaSetButton.fontSize()`、`SegmentedControl.itemFontSize`、
  `DurationInput.labelFontSize`、`ChaSetLabel.pixelSize` 等），**保持数值不变**、只换来源。
- **显式行高补齐**：CardTitle(`leading-none`+`tracking-tight`)、CardDescription(`leading-bodyLarge`)、
  AlertDialog/Dialog 文本 → Qt 补 `lineHeight` + `lineHeightMode: Text.FixedHeight`。

## 环境坑（本机，重要）
- **bash shim 坏**：`dirname`/`cd`/`ls`/`cat` 缺失 → 每条命令前置
  `export PATH="/usr/bin:/bin:$PATH"`；查文件用 `node -e`。
- **git 读写沙箱陷阱**：`git commit/push` 等**写**操作必须 `dangerouslyDisableSandbox: true`，
  否则静默虚拟化（返回 0 但不落盘）。本机 `refs/remotes/*` 写不进去 → push 用显式
  refspec `git push origin <local>:<remote>`。
- **PowerShell 输出捕获坏**（`Write-Output` 不回传）→ 构建命令**重定向写日志文件**，
  再用 bash `tail` 读；`Set-Content` 写探针文件证明 PS 本身能执行。
- **Qt 构建工具链**：本机此前**从未构建过** Qt demo。必须用
  `Microsoft.VisualStudio.DevShell.dll` + `Enter-VsDevShell`（VS18 Community）先进 MSVC 环境，
  并且**显式** `-DCMAKE_C_COMPILER=cl -DCMAKE_CXX_COMPILER=cl`——否则 CMake 会误选 MinGW 的
  gcc 去链 MSVC 版 Qt，链接阶段炸。构建成功后 `qt/build/QtChaSetDemo.exe` 可用。
- **`pnpm install` 在沙箱下不建 junction**（留下 333 个空目录），导致 vitest `ERR_MODULE_NOT_FOUND`。
  修复脚本 `%TEMP%\repair-pnpm-links.mjs`：扫 `node_modules/**/node_modules` 下空包目录，
  按 `pkgName(link)===pkg` 校验后重建 junction 到 `.pnpm/<escaped>@<ver>/node_modules/<pkg>`；
  3 个真缺的包用 `npm pack` 从 registry 取。
- **`qml.exe` 无输出**：需 `QT_QPA_PLATFORM=offscreen QT_FORCE_STDERR_LOGGING=1`，
  且 QML 根要有可见 `Window`（`visible:true`）+ `Timer` 调 `Qt.quit()`。
